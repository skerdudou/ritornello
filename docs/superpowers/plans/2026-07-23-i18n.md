# Internationalisation (i18n) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to execute this plan, dispatching one subagent per task. Each task is independently testable and leaves the whole workspace compiling.

**Goal**
Rendre l'interface de ritornello multilingue (anglais de base embarqué + français, extensible) : texte d'affichage (console/OLED), messages de validation, et pages web — via un catalogue Rust partagé, avec des packs de langue décentralisés par composant. Aucune régression : chaque tâche laisse `cargo test --workspace` vert.

**Architecture**
- Nouveau crate partagé `ritornello-i18n` : `Catalog` à deux couches indépendantes (`own` du composant + `common` du crate), chargé depuis l'anglais embarqué puis surchargé par des packs TOML externes sous `RITORNELLO_LOCALES` (défaut `/etc/ritornello/locales`). Résolution par clé `own → common → clé`. Dégradation best-effort, jamais de panique.
- Propagation runtime : le cœur pousse la langue courante aux plugins Source via `SourceReq::SetLocale(String)` sur le canal IPC existant. Console (Display) et mce (Input) n'ont pas de texte propre → non concernés.
- Sélecteur sur la page de statut du cœur : `GET`/`PUT /api/locale`, calque exact de `/api/audio-output` (mpsc vers la boucle `select!` de `main.rs`).
- Page web : rendu **serveur** via le même catalogue Rust. La page de statut lit un `Arc<tokio::sync::RwLock<Catalog>>` partagé, réécrit par `Core::set_locale`. La page d'admin radio substitue des jetons `{{clé}}` côté serveur.
- Persistance : `PersistedState.locale: Option<String>` (`None` = anglais).

**Tech Stack**
Rust (workspace Cargo), tokio, axum 0.7, serde/serde_json, toml 0.8, tracing, async-trait. Tests = modules `#[cfg(test)]` internes au fichier testé (convention du dépôt). Tests exécutés sous WSL.

## Global Constraints

- Portée : une seule livraison complète : fondation + texte Rust (affichage + validation) + pages web.
- Langue de base : anglais, embarqué dans chaque binaire (`include_str!`), filet de dernier recours toujours résolu.
- Packs additionnels : fichiers TOML externes, décentralisés par composant : `<root>/<composant>/<lang>.toml`.
- Vocabulaire commun : catalogue `common` embarqué dans le crate partagé `ritornello-i18n`, réutilisable sans duplication ni appel IPC.
- Résolution par clé : `own` du composant → `common` → anglais embarqué en dernier recours dans chaque couche. Traduction manquante = repli anglais par clé.
- Traduction web : rendu serveur via le même catalogue Rust (pas d'i18n en JS, pas de catalogue exposé en JSON).
- Propagation : langue courante poussée aux plugins Source via `SourceReq::SetLocale(String)` sur le canal IPC existant.
- Sélecteur : sur la page de statut du cœur (`GET`/`PUT /api/locale`), calque de `/api/audio-output`.
- Persistance : `PersistedState.locale: Option<String>` (`None` = anglais de base).
- Hors périmètre : messages de log/erreur internes (anyhow/tracing) ; détection auto de langue ; pluriels/genre.
- SetLocale voyage sur le canal Source existant, atteint radio+cd seulement ; console/mce n'ont rien à faire.
- La page de statut rend dans la langue COURANTE modifiable à chaud → le `Arc<RwLock<Catalog>>` partagé est l'unique source, écrit par `Core::set_locale`/la boucle `main`, lu par le handler de statut.
- Langues disponibles = celles du CŒUR (`en` + packs `core/*.toml` présents), pas une union entre plugins.
- Interpolation : `str::replace("{n}", &v.to_string())` après `catalog.get`, aucun moteur de template.
- L'anglais embarqué est la base toujours présente ; un pack/clé manquant dégrade par clé vers l'anglais.
- Ne jamais éditer les fichiers générés ; messages de commit et commentaires de code en français (convention du dépôt).

  ```rust
  //! Catalogue i18n partagé de ritornello.
  //!
  //! Deux couches indépendantes par composant :
  //! - `own` : anglais embarqué du composant (`en.toml`), surchargé par le pack
  //!   externe `<root>/<composant>/<lang>.toml`.
  //! - `common` : anglais embarqué dans ce crate, surchargé par
  //!   `<root>/common/<lang>.toml`.
  //!
  //! Résolution par clé : `own` → `common` → la clé elle-même (filet de secours).
  //! Interpolation : le composant fait `catalog.get(key)` puis
  //! `str::replace("{n}", &n.to_string())` (aucun moteur de template).

  use std::collections::HashMap;
  use std::path::Path;

  /// Vocabulaire commun anglais embarqué dans le crate.
  const COMMON_EN: &str = include_str!("locales/common_en.toml");

  /// Parse pur d'un pack TOML plat (`clé = "valeur"`). TOML invalide → map vide.
  /// Séparé de l'accès disque pour être testable (comme `audio_output::parse_device_list`).
  pub fn parse_pack(s: &str) -> HashMap<String, String> {
      toml::from_str(s).unwrap_or_default()
  }

  /// Surcharge `base` avec le pack TOML lu sur disque en `path`. Fichier absent :
  /// silencieux (cas normal). TOML illisible : `warn` loggé, `base` inchangée.
  fn overlay_from_disk(base: &mut HashMap<String, String>, path: &Path) {
      let Ok(text) = std::fs::read_to_string(path) else {
          return;
      };
      match toml::from_str::<HashMap<String, String>>(&text) {
          Ok(ext) => base.extend(ext),
          Err(e) => tracing::warn!("pack i18n {} ignoré (TOML invalide): {e}", path.display()),
      }
  }

  pub struct Catalog {
      own: HashMap<String, String>,
      common: HashMap<String, String>,
  }

  impl Catalog {
      /// Construit le catalogue d'un composant pour une langue donnée.
      /// Part de l'anglais embarqué (`own_en` pour `own`, `COMMON_EN` pour
      /// `common`), puis superpose les packs externes présents et valides.
      /// Jamais de panique : un pack absent ou invalide laisse l'anglais.
      pub fn load(component: &str, locale: &str, root: &Path, own_en: &str) -> Catalog {
          let mut own = parse_pack(own_en);
          let mut common = parse_pack(COMMON_EN);
          overlay_from_disk(&mut common, &root.join("common").join(format!("{locale}.toml")));
          overlay_from_disk(&mut own, &root.join(component).join(format!("{locale}.toml")));
          Catalog { own, common }
      }

      /// Résout une clé : `own` → `common` → la clé elle-même.
      pub fn get(&self, key: &str) -> &str {
          self.own
              .get(key)
              .or_else(|| self.common.get(key))
              .map(String::as_str)
              .unwrap_or(key)
      }
  }
  ```

  /// Noms de langues disponibles à partir des noms de fichiers d'un répertoire
  /// `core/` : `en` (toujours) + chaque `<lang>.toml`. Fonction pure, testable,
  /// séparée de l'accès disque (comme `audio_output::parse_device_list`).
  pub fn parse_available_locales(filenames: &[String]) -> Vec<String> {
      let mut out = vec!["en".to_string()];
      for f in filenames {
          if let Some(stem) = f.strip_suffix(".toml") {
              if stem != "en" && !out.iter().any(|x| x == stem) {
                  out.push(stem.to_string());
              }
          }
      }
      out
  }

  /// Langues du cœur = `en` + les packs `<root>/core/*.toml` présents.
  pub fn list_locales(root: &std::path::Path) -> Vec<String> {
      let names: Vec<String> = std::fs::read_dir(root.join("core"))
          .map(|rd| {
              rd.filter_map(|e| e.ok().map(|e| e.file_name().to_string_lossy().into_owned())).collect()
          })
          .unwrap_or_default();
      parse_available_locales(&names)
  }
